第一次設定教學（點開展開）

需要的是你的個人 Google 帳號，以下整套流程都用同一個帳號完成。免費、不需要信用卡。

1. 建立 Google Cloud 專案

  1. 到 Google Cloud Console 用你的 Google 帳號登入。
  2. 最上方專案選單 → 新增專案 → 取個名字（例如 airp-sync） → 建立。
  3. 確認上方已切到這個新專案。

2. 啟用 Google Drive API

  1. 左側選單 → API 和服務 → 程式庫。
  2. 搜尋 Google Drive API → 點進去 → 啟用。（另一個 Drive Activity API 不需要）

3. 設定同意畫面（Google Auth Platform）

  1. 左側 → API 和服務 → Google Auth Platform。
  2. 按 Get started / 開始使用。
  3. Branding：App 名稱填例如「對戲」；支援電子郵件選你的 Gmail。
  4. Audience：User type 選 外部（External）。
  5. 聯絡 email 填你的信箱 → 完成。

4. 把自己加進測試使用者

  1. 「Google Auth Platform」→ Audience（對象） 分頁。
  2. 確認 Publishing status 是 Testing（測試）。
  3. Test users → + Add users → 填你要同步的那個 Gmail（之後各裝置都要登入它） → 儲存。

5. 建立 OAuth Client ID

  1. 「Google Auth Platform」→ Clients（用戶端） 分頁 → + Create client。
  2. Application type：選 網頁應用程式（Web application）。
  3. 名稱隨意（例如 airp-web）。
  4. Authorized JavaScript origins：點 Add URI，填你打開這個網站時看到的網址（協定 + 網域，例如 https://kimmchii.net，結尾不要有斜線）。
  5. Authorized redirect URIs：留空。
  6. 建立 → 會給你一組 Client ID（像 xxxx.apps.googleusercontent.com） → 複製。

6. 回到這裡使用

  1. 把 Client ID 貼進下方欄位。
  2. 第一台裝置：按 連結 Google → 跳到 Google 授權頁。因為是測試模式，會看到「未經驗證」警告 → 點 進階 → 繼續前往 → 同意。
  3. 連結後按 上傳到雲端 建立第一份雲端備份；可勾選 自動把變更上傳到雲端。
  4. 另一台裝置：貼同一組 Client ID → 連結 Google（用同一個 Gmail） → 按 從雲端下載 → 重新載入後接上原本的對話。

Client ID 是公開資訊（不是密碼），但它綁定你在第 5 步填的網址，別人拿去別的網域也用不了，可以放心貼在這裡。記得各裝置的 Gemini 金鑰要各自填一次（同步不含金鑰）。

暫時無法繼續回覆

目前模型：

已達 Gemini 免費額度或短時間請求過快（429）。稍等一下再試就好；如果你常常聊得很頻繁，可以考慮在 Google AI Studio 開通付費 Tier。

小提醒：免費額度有每分鐘與每天兩種上限。短時間連發容易撞到「每分鐘」那條，稍候即可；若聊整天才撞到，就是「每天」上限了，要等隔天重置或升級方案。
